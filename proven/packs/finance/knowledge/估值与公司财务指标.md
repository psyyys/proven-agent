# 估值与公司财务指标

## 1. 常用估值倍数

| 指标 | 公式 | 说明 |
|---|---|---|
| 市盈率 P/E | 股价 / 每股收益 | 亏损公司的市盈率为负或无意义，计算行业市盈率时应排除 |
| 市净率 P/B | 股价 / 每股净资产 | 适合银行等资产密集型行业 |
| 市销率 P/S | 市值 / 营业收入 | 适合尚未盈利的公司 |
| 股息率 | 每股股息 / 股价 | 注意小数与百分数（0.02 = 2%） |
| EV/EBITDA | 企业价值 / EBITDA | 企业价值 = 市值 + 净债务；本数据没有债务信息，无法直接计算 |
| 盈利收益率 | 每股收益 / 股价 = 1 / 市盈率 | 可以和债券收益率比较 |

## 2. 行业比较的方法

- **用中位数，不用平均数**：市盈率分布右偏，个别公司盈利接近 0 时市盈率可达几百倍，会严重拉高平均数。
- **排除负值和缺失值**，并说明排除了多少家公司。
- **简单平均与市值加权**：简单平均反映"典型公司"，市值加权反映"指数整体"，两者可能差异很大，要说明用的是哪一种。
- 不同行业的合理估值水平本来就不同（如科技与公用事业），跨行业比较要结合增长和风险。

## 3. 快照数据的局限

- 财务快照只代表某一时点。股价每天变化，盈利数据通常是过去 12 个月合计（TTM），两者的时间不完全一致。
- **原始快照没有注明日期时，不能和其他来源、其他年份的数据直接对比**，结论中要说明这一点。
- 成分股名单是当时的名单，用它回看历史表现会有幸存者偏差。

## 4. CAPE（周期调整市盈率）

- CAPE = 实际价格 / 过去 10 年实际盈利的平均值，由 Robert Shiller 提出，用于平滑经济周期对盈利的影响。
- 历史上 CAPE 较高时，之后 10 年的平均收益往往较低，但它对短期涨跌几乎没有预测力。
- 盈利收益率（1 / 市盈率）减去长期国债收益率，是股权风险溢价的一种常用近似。
