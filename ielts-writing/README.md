# Quill · 雅思与学术写作工坊

一个帮你练习英文写作的本地小网页，人文学术风格，中英双语界面。你只需要**打字**：读教程卡片 → 写答案 → AI 纠错、分析句子、打分 → 追问老师 → 进入下一单元。

接入任何 **OpenAI 兼容接口**（DeepSeek、Kimi、通义千问、智谱、OpenAI、各类中转站）。

## 功能

| 模块 | 说明 |
| --- | --- |
| 🏠 首页仪表盘 | 今日推荐练习、连续练习天数、经验值与等级、四项能力雷达图（TR/CC/LR/GRA）、常见错误、快捷入口 |
| 🎯 雅思写作课程 | 5 个阶段、14 个单元：从「简单句」到 40 分钟完成 Task 2，以及 Task 1 |
| 🎓 学术写作课程 | 11 个单元：正式语体、名词化、语气缓和、论点句、段落统一、让步反驳、证据与解释、衔接、转述、摘要、反向提纲。每个单元标注它能提升的雅思评分项 |
| 🧰 微技能工具箱 | 5 分钟一个的小练习：升级句子、精简、缓和语气、仿写、找错、搭配、限时冲刺、范文跟打 |
| ↔️ 左右分栏 | 左边是教程 / 提示 / 批改 / 追问四个标签页，右边固定是写作区；中间分隔线可拖动，双击还原 |
| 📖 卡片式教程 | 每个知识点拆成几张短卡片：讲解 → 错误 vs 正确对比 → 打一句话的小测 |
| ✏️ 打字练习 | AI 按单元出题，也可以粘贴自己的题目；字数统计、计时、草稿自动保存 |
| 🔍 批改 | 原文中标出错误、逐条纠错讲解、句子结构分析、改进版本；完整作文按四项标准给分 |
| ⌨️ 范文跟打 | 跟着高分范文打字，实时显示对错、速度和准确率，打完给出值得记住的表达。不消耗 API |
| 💬 追问老师 | 提交前可以问思路，提交后可以问批改 |
| 📝 模考 / 句子分析 / 写作日志 | 计时模考；任意长难句拆解；历史记录与「AI 分析我的弱点」 |
| 🍃 打字特效 | 落叶（默认，淡淡的绿色落叶）、墨迹、微光、火花（原 Power Mode）、关闭；可选轻柔或打字机按键音 |
| 🌐 中英双语 | 右上角一键切换中文 / English 界面；批改讲解语言可单独设为中文、英文或中英对照 |
| 🌗 浅色 / 深色 | 纸张质感的浅色主题和暖调深色主题，可跟随系统 |

## 使用方法

需要 [Node.js](https://nodejs.org/) 18 或以上版本（装 LTS 版即可），不需要安装任何依赖。

### 最快：双击启动

- **Windows**：双击 `启动.bat`
- **macOS**：双击 `启动.command`（第一次如果提示无法打开，右键 → 打开）

会弹出一个黑色窗口并自动打开浏览器。**练习时别关这个窗口**，关掉它就停止运行了。

想更方便：Windows 右键 `启动.bat` → 发送到 → 桌面快捷方式；macOS 把 `启动.command` 按住 ⌘+⌥ 拖到桌面生成替身。以后从桌面双击即可。

第一次打开后，点网页右上角 **⚙** 设置，填写接口地址、API Key 和模型名，保存后在这个浏览器里会一直记住。界面语言、讲解语言、主题、打字特效也都在设置里。

### 命令行启动

```bash
cd ielts-writing
npm start          # 启动并自动打开浏览器
#  浏览器打开 http://localhost:3000
```

也可以把 `.env.example` 复制为 `.env`，在里面填写 API 配置，效果和网页「设置」一样。

### 配置示例

| 服务 | API_BASE_URL | MODEL |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

> 批改质量取决于模型能力，建议用各家较强的模型。推理模型（如 `deepseek-reasoner`）也可以用，只是批改会慢一些。

## 文件结构

以下路径都在 `ielts-writing/` 文件夹内：

```
启动.bat / 启动.command      双击启动（Windows / macOS）
server.js                   本地服务：提供网页 + 转发请求到你的 API（Key 不会暴露给浏览器以外的地方）
public/index.html           页面骨架
public/css/style.css        样式（人文学术风，浅色 / 深色）
public/js/i18n.js           中英文界面文字
public/js/content/ielts.js     雅思写作课程
public/js/content/academic.js  学术写作课程
public/js/content/toolkit.js   微技能工具箱、范文、模考配置
public/js/effects.js        打字特效与按键音
public/js/app.js            页面、练习流程、批改展示、提示词
```

想加单元或改教程，改 `public/js/content/` 里对应的文件就行：每个单元由几张卡片（`cards`）和一个练习（`exercise`）组成，中英文用 `B('中文', 'English')` 写在一起。

练习记录、进度和设置保存在浏览器的 localStorage 中，换浏览器或清除网站数据会丢失。旧版本的练习进度会自动保留。
